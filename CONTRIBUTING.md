# Contributing

Anyone can research, prototype, or lead an implementation of prediction markets on Bitsocial.
You can contribute a small finding, work in an existing client, or build an independent app.

## Good first contributions

- Verify how to discover a Trueo market and read its rules and status from public interfaces.
- Sketch a market card with question, outcome state, discussion, and trading entry point.
- Connect one market page to a real Bitsocial thread.
- Document a community's interest in a specific market and what would make it useful.
- Research another settlement protocol using the questions in the
  [Trueo note](research/trueo.md).

Use [issues](https://github.com/bitsocialnet/prediction-markets/issues) to share questions, findings,
and implementation links. If you want to lead a prototype, describe the smallest useful result
you intend to build and the help you need. An issue is useful for coordination, but independent
experiments are welcome.

## Research contributions

Link primary sources near factual claims and record the research date. Distinguish documented
behavior, observed behavior, and hypotheses. For contract observations, include the network,
deployment/version, and block reference where relevant. Preserve unresolved questions instead of
guessing that an API or feature exists.

Keep the README's research map current when work starts or a prototype becomes available. A
partnership should only be described as agreed when the parties have actually agreed to it.

## Prototype contributions

Include setup instructions, a reproducible demo, the dependencies involved, and the behaviors
you verified. Prefer a small complete participant flow. Discuss shared protocol conventions
through [BSIPs](https://github.com/bitsocialnet/BSIPs) if interoperability requires them; an initial
client experiment can begin with ordinary links and existing APIs.

Contributions are made under this repository's [GPL-3.0-or-later license](LICENSE). Preserve
third-party notices and check the licenses of any code or assets you reuse.
